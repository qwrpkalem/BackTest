나온 숫자인지 알 수 없기 때문에 반드시 함께 남깁니다.

>
> **v3↔v4↔v5** 비교 = 포지션 사이징 방식의 순효과 (진입·청산 조건, 매매 목록 동일).
> v4는 베팅이 커져 악화(현금부족 23.9%), v5는 절반으로 줄여 MDD 11.35%p 개선.
>
> ⚠️ 단 **대조군 검증** 결과, v5의 개선은 R 배분 로직이 아니라 **평균 베팅 축소** 때문입니다.
> R 변동을 없애고 같은 평균 노출(7.594%)로 고정하면 CAGR +3.29% / MDD -24.43% 로,
> 위험조정 수익(CAGR/|MDD|)이 오히려 더 높습니다 (0.135 vs 0.127).
>
> **v5↔v6** 비교 = 청산 구조의 순효과 (진입 조건은 거래대금 배수만 다름).
> 트레일링을 폐지하고 고정손절 + 20일선 이탈로 바꾸자 **+24% 도달률 10.7% → 17.5%,
> CAGR +3.55% → +6.65%, MDD -27.92% → -22.98%** 로 전 지표가 개선됐습니다.
> 승률은 오히려 낮아졌지만(35.6% → 32.7%) 평균 수익이 +10.53% → +16.53% 로 커졌습니다.
>
> **v6·v7·v8** = 거래대금 배수(1.5/1.4/1.3)만 다른 검증 세트. 차이가 미미해 v6 유지.
>
> **v8↔v9** 비교 = R 사이징 폭의 순효과. 베팅을 2배로 키우니 수익도 낙폭도 거의 2배
> (CAGR +6.30% → +10.78%, MDD -23.98% → -38.46%). 전형적인 레버리지 효과이며
> 위험조정 수익은 0.263 → 0.280 으로 큰 차이가 없습니다. 현금부족은 34.1% 재발.
>
> **v9↔v10** 비교 = 코스피 60일선 시장필터의 순효과. **수익만 줄고 낙폭은 그대로**
> (CAGR -2.65%p, MDD -38.46% → -38.55%). 하락장(2022 -32.68% → -15.02%)은 방어했으나
> 상승장(2021 +67.02% → +18.11%)에서 놓친 기회가 더 컸습니다.
>
> **v8·v9·v10·v11 = 사이징 × 시장필터 2×2 격자** (진입·청산 조건 동일)
>
> | | 필터 없음 | 필터 있음 |
> |---|---|---|
> | **0.5R** (최대 12.5%) | v8: +6.30% / -23.98% | v11: +5.34% / **-21.39%** |
> | **1R** (최대 25%) | v9: **+10.78%** / -38.46% | v10: +8.13% / -38.55% |
>
> 시장필터는 **두 사이징 모두에서 수익을 깎았고**, 낙폭 방어는 0.5R에서만 나타났습니다
> (1R에서는 이미 보유한 포지션의 평가손이 지배해 진입 차단이 무력화됨).
> 위험조정 수익(CAGR/|MDD|)은 **필터 없는 쪽이 항상 우수**합니다.
>
> **목적별**: 절대 수익 → **v9**(+10.78%) / 낙폭 최소 → **v11**(-21.39%) / 균형 → **v9·v8**

> **v12·v13·v14 = v12 기준 두 갈래 실험**
>
> | 버전 | 변경 | CAGR | MDD | 손익비 | +24% 도달률 |
> |---|---|---|---|---|---|
> | v12 | 기준 | **+13.51%** | -30.31% | 2.60 | 19.4% |

> **v14 가 앞서 목표했던 "도달률 30%"를 달성**했습니다(31.0%). 진입 필터로는 16%가
> 천장이었는데, 20일선 이탈이 +24% 도달 전 종목을 미리 잘라내던 것이 원인이었습니다.
> 다만 패자가 모두 -8% 까지 가면서(손실의 92.8%가 -8~-9%) 낙폭이 커졌습니다.
>
> **v12·v13·v14·v15 = 사이징 × 20일선 규칙 2×2 격자**
>
> | | 20일선 기존 | 20일선 +24% 후에만 |
> |---|---|---|
> | **1R** | **v12: +13.51% / -30.31%** (0.446) | v14: +10.39% / -38.47% (0.270) |

>
> 20일선 규칙 변경은 **두 사이징 모두에서 위험조정 수익을 크게 떨어뜨립니다.**
> 도달률은 19% → 31% 로 오르지만 승률이 떨어지고 거래가 36% 줄어 성과로 연결되지
> 않습니다. **"도달률을 올리는 것"이 곧 성과 개선은 아니었습니다.**
>
> **목적별**: 절대수익·위험조정 → **v12** / 낙폭 최소 → **v13**(-18.84%)

## 새 버전 아카이브 방법

백테스트를 돌린 **직후**(스펙을 다시 수정하기 전에) 아래를 실행하면 됩니다.

```bash
python src/archive_version.py v3 "설명"
```

`backtest_spec.md`와 `output/report.md`를 `output/history/v3/`에 함께 복사합니다.

> ⚠️ v1 스펙은 이 규칙이 없던 시절에 v2로 덮어써져 원본이 유실됐고, 세션 기록에서
> 복원한 사본입니다([v1/spec.md](v1/spec.md) 상단 주석 참고). 같은 일이 반복되지
> 않도록 위 스크립트를 쓰세요.
